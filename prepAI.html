System Abstract

AgentVerse is an end-to-end, multi-agent mock interview platform designed to simulate rigorous technical and behavioral interviews. Driven by Llama-3 models over Groq and orchestrated via FastAPI and Next.js, the system processes candidate resumes, executes real-time conversational interview turns, calculates precise multi-category scores, and persists performance scorecards directly to AWS DynamoDB.

Features low-latency sub-second response times, Web Speech voice interaction support, JWT-authenticated candidate persistence, and strict JSON normalization to prevent evaluation schema drift.

The 4-Agent Intelligence Architecture

AgentVerse orchestrates four distinct agent design patterns to deliver full-lifecycle interviewing.

Model-Reflex Agent

interview_agent.py

Evaluates state and dialogue history to dynamically generate sub-second technical probes and follow-ups.

Goal-Based Agent

planner_agent.py

Structures interview progression targeting specific role distributions (e.g. 30% System Design, 30% Resume Projects).

Utility-Based Agent

evaluation_agent.py

Calculates continuous utility metrics across accuracy, communication, and problem-solving via JSON mode.

Learning Agent

roadmap_agent.py

Analyzes candidate weaknesses to output a tailored 7-day study plan and targeted practice topics.
